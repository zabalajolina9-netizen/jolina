About the Website

Your beauty guide online

This website is an educational HTML and CSS project created to present O.TWO.O cosmetics in a clear, attractive, and organized format.

Its rose-gold and blush-pink design creates a consistent beauty-brand appearance. Visitors can use the navigation menu to explore the website and learn about the cosmetics collection.

  • Home: introduces the website and highlights featured products.
  • About: provides information about the website and its product range.
  • Product: displays product details and descriptions.
  • Contact: provides a place for visitor inquiries and contact details.
